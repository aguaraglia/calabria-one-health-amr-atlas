# Materiali di curatela

Questa cartella contiene gli input usati per ricostruire il catalogo e i layer: decisioni di inclusione (247 righe: 19 incluse, 12 dubbie, 216 escluse), esummary PubMed, lo stato dei testi integrali, il disclaimer EpiCentro consultato per la licenza AR-ISS e le risposte Nominatim del presidio Mater Domini (nessun oggetto ospedaliero, nessun punto usato). Non contiene il report regionale ICA/MDR 2022-2023, i materiali di dati.regione.calabria.it, delle ASP, delle aziende ospedaliere, di ARPACAL, del catalogo open data dell'IZS del Mezzogiorno né del rapporto OsMed.
